Admin-elevering i én linje. Ingen installasjon, ingen agent, ingen admin-rettigheter, ingen trapp. Bare heisen.

PowerShell — trykk for etasje
PS> irm heis.d0.si/install.ps1 | iex
→ heisen er oppe - 05:59:59 igjen

Klikk kommandoen for å merke den, så Ctrl+C. Kjør den i en PowerShell hvor som helst — på skrivebordet eller over SSH. Cold start: ~1 sekund.

før du trykker
Heisen går bare i den bygningen den er montert i. Kjør den på en Windows Cloud PC (Windows 365 / AVD) der Admin By Request allerede er installert — det er dialogene den klikker seg gjennom. Uten ABR er det ingen heis å hente, bare en tom sjakt.
0 avhengigheter
Én fil. Ingen AutoHotkey, ingen agent å holde i live, ingenting å rydde etterpå.
0 admin-rettigheter
Trenger ikke være admin for å be om å bli det. Det er liksom hele poenget.
Ingen tilkobling
Funker med RDP koblet fra og skjermen mørk. Dialogene styres med vindusmeldinger, ikke mus.
Session 0 → topp
Fra SSH som ikke ser skrivebordet, heiser den seg selv inn i den interaktive sesjonen.

1Hva den gjør

Starter Admin By Request med /Elevate og klikker seg gjennom dialogene for deg — «Yes», så «OK» — og verifiserer at nedtellingen faktisk startet før den melder tilbake. Ikke gjett, sjekk. Så vet du at heisen faktisk kom opp.

2Flere etasjer

| iex kan ikke sende argumenter — den slipper deg bare av i første etasje (elevér). Vil du til en annen knapp, lag en script-blokk:

# hent kilden én gang, kall den med hvilken knapp du vil
$h = 'https://heis.d0.si/install.ps1'
& ([scriptblock]::Create((irm $h))) -Status    # hvilken etasje står vi i?
& ([scriptblock]::Create((irm $h))) -Finish    # kjør heisen ned, avslutt økta

Eller last den ned og kjør den som en helt vanlig fil:

.\Heis-Standalone.ps1              # elevér, om du ikke alt er oppe
.\Heis-Standalone.ps1 -Status      # rapportér og gå ut
.\Heis-Standalone.ps1 -Finish      # kjør ned
.\Heis-Standalone.ps1 -Uninstall   # fjern relé-oppgaven den registrerer

4Hvordan den kommer opp

En SSH-shell lander i session 0 — kjelleren, uten skjerm. Ingenting den gjør når frem til skrivebordet. Så heisen tar en omvei:

▲
Interaktiv sesjon
Reléet fyrer, klikker gjennom dialogene med vindusmeldinger. Ingen mus å flytte — funker mørklagt.
·
Planlagt oppgave
Registreres første gang. Broen over sesjonsgrensen som vindushåndtak ikke krysser.
0
Session 0 — SSH
Her starter du. Ser ikke skrivebordet. Trykker på knappen likevel.

Eneste krav: at en interaktiv sesjon finnes. Den kan være frakoblet, men noen må ha logget inn siden forrige omstart. Skriver en kopi til %LOCALAPPDATA%\Heis, fordi reléet trenger en fil på disk å peke på.
